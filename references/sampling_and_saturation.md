# 样本、覆盖与饱和度

仅在制定定性研究或可用性测试样本计划时读取。这里给出规划依据，不替代抽样设计或统计功效分析。

## 可用性问题发现模型

Nielsen 与 Landauer 的经典模型用 `1 - (1 - p)^n` 描述 n 名参与者发现某类问题的概率，其中 p 是单名参与者发现该问题的概率。历史文献曾用特定任务中的 p 作示意，但它不是可移植的普遍常数：

- p 会随任务、产品、问题严重度和用户群变化。
- 单一小组的历史经验不能替代覆盖矩阵；不同关键分层需要分别观察。
- 它估计问题发现机会，不估计总体发生率。
- Faulkner 的重抽样研究显示，小样本测试的实际覆盖波动很大。

因此先从同类历史研究、先导轮次或明确的情景假设估计发现概率与目标覆盖，再根据新问题出现曲线、关键任务覆盖和风险决定是否追加。没有依据时不要反推一个“标准人数”；`saturation_planner.py` 不提供内置情景，也不会代填这些参数。

## 主题饱和度

Guest、Bunce 与 Johnson 在特定同质样本和编码口径下观察到基础主题较早出现并趋于稳定；这个观察不能脱离其研究对象、分析深度和停止定义，换算成通用访谈人数。

初始招募人数也必须由研究者按具体人群、分层和风险显式给出。更可靠的停止依据包括：

1. 连续若干次访谈没有出现新的、与研究问题相关的主题。
2. 已有主题的属性、反例和分群差异得到足够解释。
3. 关键用户群、极端案例和高风险场景已覆盖。
4. 团队能说明继续招募可能改变哪个决策。

异质人群、罕见行为、高风险决策或分群报告通常需要更多样本。便利样本即使数量大，也不能弥补系统性覆盖缺失。

## 报告方式

- 写清招募渠道、纳入/排除标准、实际完成数和退出数。
- 用“本样本中 X/Y”描述观察，不把小样本频率写成总体比例。
- 区分“没有再出现新主题”和“研究已经证明没有其他主题”。
- 为样本计划标注置信度、关键假设和若假设错误会怎样。
